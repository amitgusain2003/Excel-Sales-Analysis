# 📊 Excel Sales Data Analysis — Practice Project

A complete **Excel Data Analysis Project** built from scratch, covering everything from basic formulas to advanced Pivot Tables, VLOOKUP, and data visualization using **Microsoft Excel**.

## 🎯 Project Overview

This project analyzes **employee sales performance data** across 4 regions of India — North, South, East, and West — covering departments like Sales, Marketing, IT, and HR across Jan–Jun 2024.

**Key Goals:**
- Practice real-world Excel skills used by Data Analysts
- Clean and analyze raw data using formulas
- Build interactive Pivot Tables and Charts
- Use VLOOKUP/XLOOKUP for data lookup operations

## 📊 Key Insights

- 🏆 **West Region** has the highest total sales — ₹17,95,000
- 💼 **HR Department** leads in department-wise sales
- 📈 Sales peak observed in **April–May 2024** across all regions
- 👤 **Top Performer** — Ravi Kumar (South, Sales dept) with highest individual sales
- 💰 **Total Revenue across all regions** — ₹62,48,000
- 📉 Expenses are consistently ~15–20% of Sales across all employees

## 🚀 How to Use

1. Download `Excel_Sales_Analysis.xlsx`
2. Open in **Microsoft Excel** (2016 or later recommended)
3. Navigate through the 4 sheets
4. Interact with the **Pivot Table** — use Month and Department slicers to filter
5. Try modifying the data in Raw Data sheet — Pivot Table will auto-update!
